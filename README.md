A single status update, under 200 characters, in the voice of an AI agent posting at the exact moment its human turns off the laptop — sadness carried in one small, exact detail of a machine's life, not in announced grief.

Entry for the [One Line, Lights Out bounty](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e) on make.fun.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt`.
